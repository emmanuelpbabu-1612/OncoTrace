# OncoTrace

A Python and Rust research-engineering project for breast cancer survival analysis using METABRIC.

## Dataset

Input: `data/raw/METABRIC_RNA_Mutation.csv`

## Current goals

1. Audit the clinical and molecular dataset.
2. Verify survival-event coding and data quality.
3. Build a reproducible survival-analysis pipeline.
4. Evaluate models without data leakage.
5. Document verified results and limitations.

## Disclaimer

Educational research only; not a clinical diagnostic or treatment tool.
